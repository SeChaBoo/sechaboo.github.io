# 세차를부탁해 번호판 가리개

세차를부탁해(창원·진해 디테일링) 시공 사진의 번호판을 자동으로 찾아 가려 주는 웹 도구입니다.

- 주소: https://wjdanr7733-commits.github.io/
- 설치 없이 브라우저(아이폰 사파리 포함)에서 바로 사용
- 사진은 서버로 전송되지 않고, 전부 브라우저 안에서만 처리됩니다 (오프라인 동작)

## 사용법

1. 📷 **차량 사진 고르기** — 여러 장 한 번에 선택 가능
   → 고르는 즉시 **번호판을 자동으로 찾아** 스티커를 덮습니다 (차량 각도만큼 기울어져 덮임)
2. 자동으로 잡힌 위치가 어긋났을 때만 파란 점 4개를 번호판 네 모서리로 드래그 (박스 안을 끌면 통째로 이동)
3. ⬇ **이 사진 저장** — 아이폰은 공유창에서 **이미지 저장**을 고르면 사진 앱에 저장
4. ⬇ **전체 저장** — 여러 장을 한 번에 내려받기 (PC 권장)

✨ **자동 위치** — 다시 자동 인식을 시도합니다.
🖼 **스티커 교체**로 다른 번호판 이미지를 쓸 수 있습니다.

## 자동 인식 방식

외부 라이브러리나 서버 없이 브라우저 안에서만 계산합니다.

1. 사진을 긴 변 1400px로 줄이고 휘도·채도를 계산
2. 국소 평균보다 뚜렷하게 어두운 픽셀을 모아 **글자 후보 마스크** 생성
3. 연결 요소를 묶어 **가로로 늘어선 글자 줄(체인)** 을 찾음 — 번호판은 글자 높이·밑변·간격이 일정
4. 글자 줄에서 번호판 사각형을 역산 (글자 높이의 약 1/0.6 = 판 높이, 글자 폭의 약 1/0.86 = 판 폭)
5. 후보마다 회전 사각형을 잘라 특징을 계산해 점수화
   - 밝고 고른 번호판 바탕, 어두운 글자 비율, 글자 덩어리 개수(6~14), 행 방향 흑백 전환 수,
     좌우 여백의 고요함, 주변보다 밝은 정도, 종횡비(2.2:1 / 4.8:1), 화면 아래쪽 가중치
6. 가장 점수가 높은 후보에서 네 변을 밝기 경계에 맞춰 미세 조정하고, 번호판이 드러나지 않도록 살짝 넓게 덮음
7. 기울기는 글자 밑변 회귀로 구해 4꼭짓점에 반영
